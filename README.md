\# MIKA Phase 18 Sales Intelligence



\## Overview



This project presents a verified sales intelligence and reconciliation dashboard developed for MIKA (Ideal Appliances Ltd).



The project focuses on multi-year sales reporting, transaction-level analysis, source reconciliation, and management reporting.



\## Main Dashboard



The main presentation dashboard is:



`phase18\_dashboard.py`



It provides:



\- Executive sales performance

\- Annual sales trends

\- Year-over-Year reporting controls

\- Phase 16 vs Phase 18 reconciliation

\- Regional sales analysis

\- Selling type analysis

\- Management conclusions

\- Data quality and reconciliation controls

\- Management recommendations



\## Reporting Scopes



\### Phase 18



Official multi-year source reporting.



\### Phase 16



Transaction-level sales analysis.



The two reporting scopes are deliberately kept separate because they represent different analytical scopes.
